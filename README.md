# QuantPilot

一款 Android 手机端量化回测与实时信号监控工具，支持 A 股和港股自选股票、多策略回测、实时行情与买卖信号推送。

## 功能特性

### 自选股票
- 支持 A 股（600519 等）和港股（01810 等）代码添加
- 实时报价显示，自动轮询刷新（开市 15 秒 / 休市 5 分钟）
- 自选列表持久化，重新打开自动加载

### 策略回测
支持 2022 年至今的日 K 线数据，包含 **10 个策略**：

| 类型 | 策略 | 逻辑 |
|------|------|------|
| 单策略 | 双均线 | SMA 10/30 均线交叉 |
| 单策略 | MACD | EMA 12/26 交叉 |
| 单策略 | RSI超卖 | RSI 超卖买入、超买卖出 |
| 单策略 | 海龟突破 | 20 日高点突破入场 |
| 单策略 | 布林带回归 | 下轨买入、中轨卖出 |
| 单策略 | ATR海龟 | 海龟 + 波动率过滤 |
| 单策略 | 假突破反转 | 跌破支撑快速收回买入 |
| 组合策略 | 体制切换组合 | 趋势/震荡自适应切换 |
| 组合策略 | 投票平均组合 | 三策略简单平均 |
| 组合策略 | 四维分散组合 | 四类策略等权每日再平衡 |

**回测统计**：总收益、买入持有基准、最大回撤、夏普比率、胜率、交易笔数、单笔最大盈亏

### 图表
- 价格走势图 + 买卖点标记（红买绿卖）
- 策略净值 vs 买入持有对比
- **双指捏合缩放、单指水平平移、上下滑动页面**
- 两张图联动同步，时间轴对齐

### 信号监控
- **盘中实时信号**：开市期间每分钟用实时价合成 K 线计算策略信号，方向变化时推送通知
- 同方向去抖，避免价格震荡时反复通知
- app 内信号徽章实时刷新，与通知保持一致
- 收盘后自动重算，次日开盘前发送持仓建议

### 折叠屏适配
支持三种显示模式（小米18Fold）：
- **展开竖屏**：顶部标签栏 + 全宽详情
- **展开横屏**：左侧股票列表 + 右侧详情
- **折叠小屏**：紧凑布局

## 构建

```bash
# 使用 Gradle 8.9+
gradle assembleRelease --console=plain --no-daemon
```

需要 JDK 17 和 Android SDK（compileSdk 35）。

## 技术栈

- Kotlin + Jetpack Compose (Material 3)
- OkHttp + 腾讯行情 API
- Coroutines + StateFlow
- Android 前台服务 + 通知推送
